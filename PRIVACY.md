# SwingFix AI — Privacy Policy

**Last updated: June 5, 2026**

SwingFix AI ("we") operates the SwingFix AI MCP server at swingfixai.io.

**Data we collect:** Golf swing image URLs and user IDs submitted via the API. Analysis results are stored in our database to enable swing history features.

**How we use data:** Solely to provide golf swing analysis and return results to the requesting agent or application.

**Data retention:** Analysis records are retained until deleted by the user.

**Third-party services:** We use Anthropic's Claude Vision API for image analysis and Supabase for data storage.
